# v0.1.0 — experimental

OpenAPI Contract Lab compara dos contratos locales con **oasdiff 1.39.0** como único motor semántico y añade explicaciones accionables. Candidato preparado en el issue #18; la publicación debe aprobarse por separado y marcarse como **pre-release**.

## Funciones reales

- Comparación CLI de dos archivos locales. No hay GUI ni servidor.
- Modelo JSON con IDs, niveles originales, severidad, compatibilidad y fuentes; se conserva el evento original.
- Diez explicaciones específicas en español; fallback neutral para otras combinaciones. Enlaces locales para fuentes conocidas.
- Informes JSON, Markdown y HTML offline; protección contra sobrescritura de archivos existentes.
- Gate `--fail-on error|warning|info|none`, predeterminado `error`, sin filtrar hallazgos del informe.

## Requisitos e instalación

**Solo Windows x64 verificado**, PowerShell 5.1 y 7. Go **1.27.4** solo para compilar desde fuente. Para comparar, descargar **oasdiff 1.39.0** por separado desde su [release oficial](https://github.com/oasdiff/oasdiff/releases/tag/v1.39.0). No se incluye en nuestro ZIP. Sin APIs de IA, servicios de pago, credenciales ni coste adicional obligatorio.

Archivos previstos: `openapi-contract-lab_0.1.0_windows_amd64.zip` y `SHA256SUMS.txt`. Antes de extraer, comprobar el SHA-256 del ZIP con `Get-FileHash` y compararlo con la línea correspondiente de `SHA256SUMS.txt`. Extraer en una carpeta nueva; conservar LICENSE, NOTICE y THIRD_PARTY_NOTICES.txt. `BUILD.txt` identifica el SHA fuente y los flags del ejecutable, cuyo hash también figura allí. Los checksums identifican bytes; no son una firma digital.

El ZIP contiene únicamente nuestra CLI, ejemplos sintéticos, notas, identificación de compilación y licencias. No incluye el SDK, oasdiff ni informes con rutas personales. El SDK no es necesario para usarlo. La [guía desde fuente](https://github.com/v1kz25/openapi-contract-lab/blob/release/0.1.0/docs/INSTALL.md) fija descargas y hashes de herramientas. Desde el repositorio, compilar con Go 1.27.4 y:

```powershell
$env:GOTOOLCHAIN='local'; $env:GOPROXY='off'; $env:GOSUMDB='off'
$env:CGO_ENABLED='0'; $env:GOOS='windows'; $env:GOARCH='amd64'
$env:GOAMD64='v1'; $env:GOFLAGS=''; $env:GOEXPERIMENT=''; $env:GOWORK='off'
go build -trimpath -buildvcs=false -o dist/openapi-contract-lab.exe ./cmd/openapi-contract-lab
```

## Uso desde la carpeta del ZIP extraído

Descargar y extraer oasdiff aparte; adaptar únicamente su ruta al ejecutar. Las opciones preceden a BASE y HEAD.

```powershell
.\openapi-contract-lab.exe --version
# openapi-contract-lab v0.1.0
$motor = 'C:\tools\oasdiff-1.39.0\oasdiff.exe' # ruta de ejemplo, adaptar
.\openapi-contract-lab.exe compare --oasdiff $motor .\examples\base.yaml .\examples\required.yaml
$LASTEXITCODE # 3: breaking, informe JSON completo
.\openapi-contract-lab.exe compare --oasdiff $motor .\examples\required.yaml .\examples\base.yaml
$LASTEXITCODE # 0: compatible
$salida = '.\informe-' + [guid]::NewGuid().ToString('N') + '.html'
.\openapi-contract-lab.exe compare --oasdiff $motor --format html --output $salida .\examples\base.yaml .\examples\required.yaml
$LASTEXITCODE # 3: HTML generado antes del gate
Invoke-Item $salida
```

`--format` admite `json` (predeterminado), `markdown` y `html`. Usar `--output` para guardar UTF-8 sin depender de redirecciones PowerShell. El destino debe ser nuevo. `--fail-on none` permite exportar sin gate; los errores operativos siguen fallando.

| Código | Resultado |
| --- | --- |
| 0 | Comprobación correcta que supera la política, ayuda o versión |
| 1 | Error de entrada, motor, renderizado o escritura |
| 2 | Argumentos inválidos |
| 3 | Informe generado; política no superada |

## Limitaciones

- Experimental: CLI y esquema de informe pueden cambiar; sin garantía de estabilidad ni adecuación a todos los contratos.
- Fixtures verificados OpenAPI **3.0.3** y casos mínimos **3.1.0**. No se afirma cobertura completa de 3.1 ni soporte verificado de 3.2; otros sistemas/arquitecturas no probados.
- oasdiff debe ser exactamente 1.39.0. Referencias externas y entradas URL/UNC deshabilitadas; comparación limitada a 30 segundos.
- Solo diez explicaciones verificadas. Una explicación fallback no añade una causa inferida ni cambia la clasificación del motor.
- Cero hallazgos no significa contratos idénticos: el changelog excluye cambios solo de descripción.
- Los informes contienen datos de contratos y rutas locales; revisarlos antes de compartirlos. No se suben automáticamente.
