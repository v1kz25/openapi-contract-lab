# v1.0.0 — candidato de primera versión estable, no publicado

El [issue #40](https://github.com/v1kz25/openapi-contract-lab/issues/40) prepara este candidato en `release/1.0.0` para revisión mediante PR hacia `main`. **No hay tag, release ni draft v1.0.0; no se ha autorizado su publicación.** `--version` identifica los bytes como `openapi-contract-lab v1.0.0`, no prueba que estén publicados. Las garantías estables descritas entrarán en vigor al aprobar y publicar la versión mediante #41.

## Alcance estable propuesto

- **Windows x64**, PowerShell **5.1 y 7**, dos archivos regulares locales revisados, oasdiff exactamente **1.39.0** como único motor semántico. Go **1.27.4** solo para construir; el ZIP no necesita SDK para ejecutarse. Coste adicional obligatorio **0 €**, operación local/offline tras obtener herramientas.
- Comandos `help`/`-h`/`--help` (también sin argumentos), `version`/`--version`, `compare`. Opciones antes de BASE/HEAD: `--oasdiff` (por defecto PATH), `--format json|markdown|html` (json), `--output` (ausente = stdout) y `--fail-on error|warning|info|none` (error). Se admite `--` y `--opción=valor`.
- Códigos **0**: ayuda/versión o informe que supera política; **1**: fallo operativo; **2**: argumentos inválidos; **3**: informe completo que no supera política. Informe solo en stdout o archivo; errores/política en stderr. Con `--output`, stdout vacío. Un fallo operativo prevalece incluso con `none`.
- Trece explicaciones deterministas en español y fallback neutral. Clasificación, evento upstream, ubicaciones y orden de hallazgos conservados. HTML/Markdown agrupados y offline, sin JavaScript ni recursos remotos; CSP y escape contextual.
- Corpus comprobado: trece pares regla/nivel **3.0.3** y cinco pares **3.1.0**: idéntico, descripción, obligatoriedad, unión con null y tipo de propiedad de respuesta. Son casos enumerados, no cobertura completa de dialectos.

Frente a v0.2.0 no se añaden funciones ni plantillas: se formaliza y prueba el contrato, se ejercitan fallos de proceso/archivos, se documenta distribución/mantenimiento y se conserva el diagnóstico de límite de salida cuando también falla el motor (#37–#39). #40 solo cambia identificación, expectativas de versión, cabecera de avisos y documentación de candidato.

## Contrato y migración desde experimental

Contrato normativo **CLI 1.x / JSON v1**, sin campo `schemaVersion`. No cambian campos, defaults ni códigos respecto a v0.2.0. Los informes existentes siguen siendo legibles; guardar versión CLI/procedencia fuera del JSON al archivarlos. `engineVersion` es la versión de oasdiff, nunca del esquema ni del productor.

Los consumidores leen campos por nombre, toleran campos opcionales adicionales y no dependen del orden de claves, escapes equivalentes, prosa ni bytes visuales. Arrays conservan orden/repeticiones; campos opcionales ausentes no equivalen a null/false. `findings` y `explanation.locations` vacíos son `[]`. ID/nivel desconocidos se conservan; nivel desconocido se normaliza a `unknown` y bloquea con política activa. Fallback no implica severidad desconocida.

Cambiar tipos/significados/campos requeridos/defaults/códigos exige major y migración; adiciones opcionales compatibles se documentan y prueban. Los datos opacos y resultados semánticos de otra versión del motor no se prometen equivalentes. Actualizar oasdiff exige issue/PR, versión/hash/licencias y revisión del corpus; cambio semántico compatible requiere al menos minor propia. Referencias normativas: [CLI](https://github.com/v1kz25/openapi-contract-lab/blob/release/1.0.0/docs/SEVERITY-POLICY.md), [JSON](https://github.com/v1kz25/openapi-contract-lab/blob/release/1.0.0/docs/OASDIFF-ADAPTER.md), [compatibilidad y mantenimiento](https://github.com/v1kz25/openapi-contract-lab/blob/release/1.0.0/docs/DEVELOPMENT.md). La rama puede avanzar: BUILD.txt identifica el SHA exacto de cada paquete.

## Revisar el ZIP local

Archivos previstos: `openapi-contract-lab_1.0.0_windows_amd64.zip` y `SHA256SUMS.txt`, todavía locales. Comparar el SHA-256 con la evidencia de la PR antes de extraer en **otra carpeta nueva**. Los checksums identifican bytes, no son firma digital. BUILD.txt identifica fuente/tree, herramientas/flags, hash del ejecutable e inventario de 20 archivos. Sin oasdiff, SDK, cachés, helpers ni informes privados incluidos.

Obtener oasdiff 1.39.0 por separado según la [guía vigente](https://github.com/v1kz25/openapi-contract-lab/blob/release/1.0.0/docs/INSTALL.md); su descarga inicial requiere Internet. Desde el ZIP extraído:

```powershell
.\openapi-contract-lab.exe --version
# openapi-contract-lab v1.0.0
$motor = 'C:\tools\oasdiff-1.39.0\oasdiff.exe' # adaptar a su ubicación local
.\openapi-contract-lab.exe compare --oasdiff $motor .\examples\base.yaml .\examples\required.yaml
$LASTEXITCODE # 3: informe completo; error/breaking
.\openapi-contract-lab.exe compare --oasdiff $motor .\examples\required.yaml .\examples\base.yaml
$LASTEXITCODE # 0: info/non-breaking
$output = '.\revision-' + [guid]::NewGuid().ToString('N') + '.html'
.\openapi-contract-lab.exe compare --oasdiff $motor --format html --output $output .\examples\openapi31\base.json .\examples\openapi31\union-null.json
$LASTEXITCODE # 3: HTML agrupado completo
```

Usar `--output` para guardar UTF-8 sin BOM/LF sin depender de redirección PowerShell; JSON usa escapes ASCII/Unicode para preservar acentos en consolas antiguas. Un destino existente se rechaza. Exit 1 puede dejar stdout o un archivo **nuevo** incompleto, incluso completo si falla el cierre: no supone éxito ni escritura atómica. Resolver el error y elegir otro nombre; no sobrescribir contratos/informes ni borrar automáticamente. Para actualizar, extraer a carpeta nueva, seleccionar rutas explícitas, probar y conservar la versión anterior para revertir. La reversión no transforma informes ya archivados.

Los nueve pares empaquetados cubren breaking, compatible, descripción, idéntico, tres plantillas incorporadas en v0.2.0 y dos casos 3.1.0. Los informes agrupados de ejemplo usan nueve eventos sintéticos y enlaces `file:///synthetic/` ilustrativos, no archivos incluidos. Abrir HTML es opcional; no existe servidor ni flujo visual nuevo que aceptar.

## Límites, privacidad y mantenimiento

- No se verifica cobertura completa 3.1, `oneOf`/`anyOf` generales, comparación entre dialectos, OpenAPI 3.2, Linux/macOS/ARM64. Sin SARIF, GUI, Overlays/autofix, comparación de carpetas ni clasificación documental/contractual. **Cero hallazgos no prueba igualdad** ni ausencia de todo cambio contractual.
- URLs/UNC/stdin y refs externas deshabilitados, configuración aislada. Deadline compartido versión/comparación **30 s**, WaitDelay **2 s**, captura por invocación **16 MiB stdout / 64 KiB stderr**. No son cuotas de entrada/RAM/CPU ni límite global para renderizado/escritura; superar captura no promete cancelación inmediata.
- No hay sandbox, aislamiento garantizado de descendientes ni auditoría completa de red/transitivos del motor. Se soportan archivos locales revisados, no un servicio para entradas arbitrarias hostiles.
- Informes, mensajes y `upstream` pueden contener rutas y datos privados. No se suben automáticamente. Revisarlos antes de compartir; reportar problemas con dos contratos sintéticos, versiones/comando/código y fragmento mínimo sin credenciales.
- Mantenimiento individual sin SLA universal; revisar avisos relevantes y herramientas antes de candidatos y por necesidad real, con issue/PR y pruebas. No es autoupdater ni vigilancia programada. No se exige ausencia absoluta de errores; un defecto de una garantía declarada sí bloquea publicar.

Proyecto **Apache-2.0**, LICENSE y NOTICE íntegros. Runtime/stdlib Go **BSD-3-Clause** y licencia completa en THIRD_PARTY_NOTICES.txt; sin módulos externos enlazados. oasdiff **Apache-2.0** externo, no distribuido en este ZIP. No se modifican licencias ni artefactos de v0.1/v0.2.
